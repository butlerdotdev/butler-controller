# Butler Controller — Claude Code Notes

## Tooling

- controller-gen pinned at v0.19.0 (butler-api Makefile `CONTROLLER_TOOLS_VERSION`). butler-controller consumes CRDs generated by butler-api. If butler-api bumps controller-gen, butler-controller's CRD expectations must stay aligned.

## Conventions

- Data-only API types without methods do not get unit test files in butler-api. Controller-side tests (envtest) cover the behavioral integration of those types.
